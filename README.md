# Basic Interactive Website

A simple beginner-friendly web project built using HTML, CSS,
and JavaScript.

## Features

- Simple and clean UI
- Dark theme
- Interactive button
- Text changes on button click
- CSS hover effect

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

BasicProject/
├── index.html
├── style.css
├── script.js
├── .gitignore
└── README.md

## How to Run

1. Download or clone the project.
2. Open the project folder.
3. Open index.html in your browser.
4. Click the button to see JavaScript working.

## Purpose

This project is created for practicing basic HTML,
CSS, JavaScript and Git/GitHub concepts.
